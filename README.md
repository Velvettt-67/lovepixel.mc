# LOVE PIXEL — A Minecraft Server

Official website and digital store for the **Love Pixel** Minecraft server ecosystem.

## Features
- **Cinematic 3D Intro & Audio**: Voxel TNT primer with interactive soundscape and particle physics.
- **Living Minecraft Ecosystem**: Interactive 3D entity models (Steve, Alex, Tamed Wolf, Creeper, Axolotl, Allay, Bee) rendered via React Three Fiber.
- **Butter-Smooth Scrolling**: Powered by Lenis with hardware momentum interpolation and smooth anchor navigation.
- **Dynamic Store & Multi-Currency**: Storefront supporting live toggle between USD ($) and INR (₹).
- **Direct Discord Integration**: Order routing and ticket workflows connected to the community server.

## Tech Stack
- **Framework**: React 19 + TypeScript + Vite 6
- **Styling**: Tailwind CSS v4
- **3D Engine**: Three.js + `@react-three/fiber` + `@react-three/drei`
- **Animations & Smooth Scroll**: Motion + Lenis
- **Deployment**: Vercel
